# Pet Walking Application

A full-stack web application designed to connect pet owners with pet walkers. The platform allows users to arrange walking appointments, manage bookings and communicate with walkers.

## Features

- **User Management:** Supports pet owners and pet walkers.
- **Booking System:** Create, manage and review walking appointments.
- **Real-Time Communication:** Live messaging between users.
- **Payment Processing:** Supports payments for walking services.
- **Reviews and Ratings:** Allows users to leave feedback on walkers.
- **Live Pet Tracking:** Provides tracking functionality during walks.

## Technologies Used

- **Frontend:** React, JavaScript
- **Backend:** PHP, Node.js
- **Database:** MySQL
- **Real-Time Communication:** WebSockets
- **Version Control:** Git

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/quantumKrish/SWE_Project.git
   ```
2. Navigate into the project directory:
   ```bash
   cd SWE_Project
   ```
3. Install the required dependencies and configure the database.
4. Start the application using the appropriate frontend and backend commands.

*Note: Setup instructions may vary depending on the project configuration.*
